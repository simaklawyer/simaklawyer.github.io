# Симаков Владислав Юрьевич — юридические документы онлайн

Одностраничный сайт-лендинг для самозанятого юриста, специализирующегося на удалённом составлении процессуальных документов: претензии, иски, возражения, жалобы, договоры, письменные консультации.

**Сайт:** https://simaklawyer.github.io/

## Возможности

- Прайс-лист по 26 направлениям права с поиском
- Форма заявки с отправкой на почту через [Formspree](https://formspree.io/)
- Согласие на обработку персональных данных и политика конфиденциальности (152-ФЗ)
- Баннер cookie-согласия
- Адаптивная вёрстка (мобильные, планшеты, десктоп)
- Структурированные данные Schema.org (LegalService)
- Готовая заготовка под Яндекс.Метрику

## Технологии

- HTML5 + [Tailwind CSS](https://tailwindcss.com/) (через CDN)
- [Lucide Icons](https://lucide.dev/) (зафиксированная версия)
- Vanilla JavaScript (без сборки)
- [Formspree](https://formspree.io/) — приём заявок без бэкенда

## Как подключить Яндекс.Метрику

1. Зайдите на [metrika.yandex.ru](https://metrika.yandex.ru/) и создайте счётчик для `https://simaklawyer.github.io/`.
2. Скопируйте номер счётчика (например, `98765432`).
3. Откройте файл `index.html`.
4. Найдите блок с комментарием «ЯНДЕКС.МЕТРИКА».
5. Замените `XXXXXXXX` на свой номер счётчика в двух местах.
6. Уберите комментарии `<!--` и `-->` вокруг кода Метрики.
7. Закоммитьте и запушьте изменения — аналитика заработает.
